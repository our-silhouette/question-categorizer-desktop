Gemini API Key Setup Guide

A simple, step-by-step beginner's guide to getting your free Google AI API key

Version 1.2  •  2026

⚡ Quick Summary (under 3 minutes)

  1. Go to aistudio.google.com/app/apikey
  2. Sign in with your Google account
  3. Click "Create API Key"
  4. Name it Question Categorizer and create a project with the same name
  5. Click "Copy key" and save it somewhere safe
  6. Paste it into the app's ⚙️ Configuration sidebar when you open Question Categorizer

Generate Your Free API Key — Step by Step

1

Open Google AI Studio

Open your web browser (Chrome, Edge, Safari, or Firefox) and click the link below:

🔗 Open Google AI Studio API Keys Page

2

Sign In with Your Google Account

If prompted, sign in using your Google account (Gmail, Google Workspace, etc.). If you don't have one, click "Create account" — it's free.

💡 Tip

Using your personal Gmail account keeps your API key free and accessible anytime.

3

Click "Create API Key"

Once signed in, click the prominent blue "Create API Key" button near the top of the page.

4

Name Your Key & Create a Project

A dialog window will appear. Follow these steps exactly:

  1. Set Key Name: In the "Key Name" field, type:
    Question Categorizer
  2. Select "Create Project": In the dropdown below the name field, click "Create Project".
  3. Enter Project Name: Type:
    Question Categorizer
    Then click the "Create project" button inside that window.
  4. Click "Create Key": Back in the main dialog, click the blue "Create key" button.
✅ Tip

Using Question Categorizer for both the key name and project name keeps your setup clean and easy to find later.

5

Copy & Save Your API Key

A final window appears showing your new API key with a "Copy key" button.

  1. Click "Copy key" (or manually select and copy the text).
  2. Open a notes app, text file, or password manager on your computer and paste the key there.
  3. Keep this file saved — you'll paste your key into the app's sidebar whenever you use Question Categorizer.
⚠️ Security Notice

Treat your API key like a private password. Never post it in emails, messages, or online. If it gets exposed, delete it at aistudio.google.com and create a new one.

6

Paste the Key into Question Categorizer

Open the Question Categorizer app. In the left sidebar under ⚙️ Configuration, you'll see a field labelled "Gemini API Key". Paste your key there and press Enter.

💡 Note

The key is only kept in memory for your current session. It is never saved to disk. You'll need to paste it each time you open the app.

7

Verify the Key Works (Optional)

You can test your key in Google AI Studio:

  1. Click "Test in AI Studio", or go to aistudio.google.com/prompts/new_chat
  2. Select Gemini 2.0 Flash as your model
  3. Type a test prompt like: "What is 2 + 2?"
  4. Click Run — if you get a response, your key is active and ready!

About the Free Tier

✅ Free tier is more than enough for typical use

Google AI Studio's free plan allows up to 1,500 requests per day with Gemini 2.0 Flash. A typical question paper categorization run uses 30–100 requests, so you can run the tool many times daily at no cost.


💡 If you hit the daily limit

You'll see a "quota exceeded" error in the app. Simply wait a few hours for the quota to reset, or visit Google AI Studio to check your usage and optionally upgrade.
